# 行程簿 TripBook

把随手记的公交 / 地铁运转记录，整理成一条清爽的时间轴。**纯本地存储，不联网。**

Windows 桌面程序，C# / WPF 编写，单文件 `TripBook.exe`（约 450 KB），双击即用，
目标电脑只需 Windows 10 1903+ / 11（系统自带 .NET Framework 4.8），无需安装 Python 或运行时。

## 功能

| | |
|---|---|
| **智能解析** | 不再依赖固定格式：以「时间 + 动作词」为锚点识别，换行折行、全角、地铁进出站合并行、纯时间标记行都能正确还原 |
| **文件名判日期** | 导入 `.txt` 时从文件名读取日期（`2026-02-09.txt`、`11.1行程.txt`、`2024_行程.txt` 只写年份也行），正文只有「月.日」时自动补上正确年份 |
| **时间轴** | 竖向轨道 + 卡片，同一条线路颜色固定；纯时间行（如「刷新换乘优惠」）渲染为时间标记，仅标注、不计入统计 |
| **统计** | 总时长、乘车次数、换乘次数、总花费、线路 / 车辆数 |
| **行程总览** | 首页展示行程总数、乘降记录、有记录的日期，并用条形图呈现「行程日期分布」 |
| **POV 总结** | 总览页跨行程汇总片段数 / 覆盖行程 / 线路 / 车号并列出每条片段；单条行程详情页也有独立的 POV 总结（含空状态） |
| **批量操作** | 列表支持 Ctrl / Shift 多选，可批量删除、批量把行程年份改为同一年（保留月日，闰年自动收敛） |
| **线路接力** | 横向链路展示 611 → 19路快线 → 162 → … 的接力关系 |
| **POV 片段** | 记录机位标签、区段、车号、时长（区段分隔支持 `-` / `--` / `->`；车号支持车牌、车队编号、资产码，可单独折行） |
| **.txt 批量导入** | 侧栏「导入」可一次选取多个 txt，自动解析并入库 |
| **导出网页** | 生成独立 HTML 报告，可直接分享 / 打印 |
| **数据目录可自定义** | 随时切换存放位置，可把已有数据一起复制过去 |
| **备份** | 每次保存自动保留 `journeys.bak.json`，损坏时自动恢复 |

## 输入格式

新建行程 → 粘贴文本 → 保存。每行一条记录，以 `HH:MM` 时间开头：

```
12.6 行程

12:00 人民中路上车 611_65028 2.00¥
12:45 无锡汽车站(锡沪西路) 上车 19路快线 11055 0.00¥
14:01 公交梅村总站上车 162_15811 0.00¥
14:59 团结路公交停车场上车 130_91879 0.00¥
16:28 海岸城公交停车场上车 888 都市观光线 75986 0.00¥
总计 4h28min 花费 2.00¥

POV:
【4K】19路快线 无锡汽车站(锡沪西路)-公交梅村总站 11055
【广角】162 公交梅村总站-团结路(先锋路) 15811
130 团结路公交停车场-海岸城公交停车场 91879
【4K广角】888都市观光线 海岸城公交停车场-胜利门 75986

POV（共 2 个）：
1.昆山 101路 4-10740
  昆山南站->轨道交通光明路站 70min
2【4K广角】 上海 陆安线（高速） S2R-0066
  安亭汽车站->中山北路中潭路 61min
```

| 位置 | 内容 | 必须 |
|---|---|---|
| 第一行 | 标题，如 `12.6 行程`（自动识别为 12 月 6 日） | 可选 |
| 每行开头 | 时间 `12:00`（全角 `１２：００` 也支持） | **是** |
| 站点 | 时间之后、动作词之前的文字 | 可选 |
| 动作 | `上车` / `下车`（缺省按「上车」） | 可选 |
| 线路 | `611`、`19路快线`、`888 都市观光线` | 可选 |
| 车号 | 3–6 位数字，或字母+数字，如 `A1234` | 可选 |
| 费用 | `2.00¥` / `2.00元` / `2.00` | 可选 |
| 总计行 | `总计 4h28min 花费 2.00¥` | 可选 |
| `POV:` 段 | 每行一个片段：`【标签】线路 起点-终点 车号`；也可写成 `序号 城市 线路 车号` + 折行 `起点->终点 70min` | 可选 |
| POV 段标题 | `POV:` / `POV（共 4 个）：` / 行中的 `和【POV】共计 2 个`（可写多段） | 可选 |
| POV 车号 | 数字车号、车牌（`苏E02574D`）、车队编号（`4-10740`）、资产码（`S2R-0066`）；可单独折一行 | 可选 |
| POV 区段分隔 | `-`、`--`、`->`、`→`、`至` | 可选 |
| POV 时长 | 区段后面写 `70min` / `1h05min` / `1小时30分`，会显示为片段时长 | 可选 |

**智能判断**：记录格式不统一也没关系——解析以「时间 + 动作词」为锚，而不是死板地按列切分。
时间行若只有时间、没有上下车动作（如 `14:41 刷新换乘优惠`），会被识别为**时间标记**，
只在时间轴标注、不参与上下车次数与统计。

**按文件名识别日期**：批量导入 `.txt` 时文件名也是日期来源，优先级为
「正文独立成行的完整日期（`2026年11月1日` / `2026-11-01`）> 正文标题的月.日 + 文件名年份 > 文件名完整日期 > 文件名月日 > 今天」。
例如 `2024_行程.txt` 内容只写 `2.9行程`，会得到 **2024-02-09**；`2026-02-09.txt` 正文没有日期时直接采用该日期。
正文月日与文件名完整日期冲突时以正文为准，文件名只用来提供年份。

**容错**：全角标点与全角数字、`611_65028` 与 `611 65028` 两种写法、费用缺失、
`2.00¥` / `¥2.00` / `2.00元`、中文时间 `11点56分` 与连写 `1156`、
动作写在站点前（`09:00 上车 八佰伴 703 85060`）、`车号:75205` 标签、
同义动作（乘车 / 搭乘 / 到站 / 抵达）、纯分隔线、
手机复制导致的折行（单独一行的 `0.00¥` 或车号会自动补回上一条）、
跨零点夜间行程（时长按次日累计）都能正确处理。

## 数据存在哪

| 内容 | 位置 |
|---|---|
| 行程数据 | `<数据目录>\journeys.json` |
| 自动备份 | `<数据目录>\journeys.bak.json` |
| 配置（数据目录、窗口位置） | `%APPDATA%\TripBook\config.json` |

默认数据目录为 **exe 同级的 `data` 文件夹**；若该位置不可写（例如放在 `Program Files`），
自动改用 `我的文档\TripBook数据`。

左下角「数据目录」可：打开目录 / 更改目录 / 导入其它 JSON / 导出全部备份。
数据是明文 JSON，换电脑时把 `data` 目录拷走即可。

## 安装（可选）

只想双击 exe 用，跳过本节即可。要装进系统（开始菜单 / 卸载项 / 快捷方式），用安装包：

**TripBook-Setup-1.2.0.exe** —— Inno Setup 6 构建的向导式安装包，页面顺序固定：

> 欢迎 → 许可协议（MIT）→ 安装位置 → 附加任务 → 准备安装 → 安装进度 → 完成

界面为简体中文，系统语言非中文时自动切 English。

* 默认装到 `%LOCALAPPDATA%\Programs\TripBook`，路径可改，**不需要管理员权限**
* 附加任务：创建桌面快捷方式、创建开始菜单快捷方式
* 完成页可勾选「立即运行」；卸载走「设置 → 应用 → 已安装的应用」或安装目录下的 `unins000.exe`

静默安装 / 卸载（脚本分发用）：

```bat
TripBook-Setup-1.2.0.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS="desktopicon,startmenuicon"
"%LOCALAPPDATA%\Programs\TripBook\unins000.exe" /VERYSILENT
```

## 从源码构建

需要 .NET SDK 6.0 或更高（目标框架 .NET Framework 4.8，Windows 自带运行时）：

```bat
dotnet build -c Release
:: 产物 bin\Release\net48\TripBook.exe
```

或直接双击 `build.cmd`，产物会复制到 `dist\TripBook.exe`。

单文件打包使用 [Costura.Fody](https://github.com/Fody/Costura)，Newtonsoft.Json 已内嵌进 exe，
发布时只需要这一个文件。

运行解析器测试：

```bat
cd tests
dotnet run -c Release
```

## 项目结构

```
TripBookApp/
├─ TripBook.csproj      项目文件（net48 / WPF / 单文件打包）
├─ App.xaml(.cs)        应用入口与全局异常处理
├─ MainWindow.xaml(.cs) 主窗口：侧边列表 + 总览 / 详情视图、批量操作
├─ EditorWindow.xaml(.cs) 新建 / 编辑行程对话框（实时解析预览）
├─ ItineraryParser.cs   文本 → 结构化行程（语义解析、文件名日期、容错规则）
├─ Models.cs            数据模型、统计与 POV 汇总（Journey / Entry / PovItem / JourneyStats / PovSummary）
├─ JourneyStore.cs      JSON 存储、批量删改、配置、数据目录切换、导入导出
├─ ViewModels.cs        界面展示用的视图模型（含总览 / POV 总结）
├─ HtmlExporter.cs      独立 HTML 报告生成
├─ TimelineSelector.cs  时间轴普通事件 / 标记行模板选择
├─ Dialogs.cs           深色风格提示 / 确认 / 输入对话框
├─ Palette.cs           配色与线路取色
├─ Theme.xaml           全局样式
└─ tests/               解析器控制台测试
```
